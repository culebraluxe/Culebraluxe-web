- CI release gates on `main` are **red** and were not run locally: rustfmt drift, 4 Rust tests, 1 osv advisory. None
  touches a picture, this deploy, or the fix; none was triaged here.
- `verify-deploy.sh` now propagates its exit code (`exit "$fail"`, printed as `VERIFY_DONE=`); earlier runs ended
  `VERIFY: FAIL` next to `VERIFY_DONE=0`, which is why that line exists.
- §5 of the harness verifies files > 8 MB by `content-length` rather than by md5 — one file today. §6 does the same,
  deliberately, so a 64 MB body never has to cross the wire to answer "is it served".
