# CIL-11 — Listing intake before `/buyers` publish

## Why

Public copy is irreversible enough to tax. Missing hero/document roles are
kill criteria we already understand.

## Units

- **A** — subjectType `listing_intake`, subjectId = property.id.
- **B** — Panel `intake-duo`. Picks: publish / hold / missing-facts.
- **C** — Evidence kinds required: measured beds/lot/media roles = FACT;
  "turnkey" / view quality = ASSUMPTION or UNKNOWN.
- **D** — Does not special-case a listing. Does not write `featured`.

## Acceptance

- Hold pick when hero or document role is missing.
- Property service remains the writer of the listing row.
