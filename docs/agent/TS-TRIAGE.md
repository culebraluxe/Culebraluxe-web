Per the one-writer rule, Phase 3 must not delete either paid gate until the owner names the canonical writer.

The final "no TS/JS outside legacy" state needs an owner decision to add `*.mts` (and ideally `*.cts`) to the ratchet or explicitly exempt it.

4. **ASK is intentionally conservative.** It is reserved for the Forge live-worker / `agent-runtime` surface named by the work order. No ASK item is safe to touch in Phase 3 without owner review.
