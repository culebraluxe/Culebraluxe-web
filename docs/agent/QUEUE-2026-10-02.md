1. **One writer per file set.** The tracks below own disjoint paths. Do not cross them — the whole reason the last
   three days cost what they did is two writers, one tree.
2. **The gate is the definition of done.** `pnpm slice:check` (T0 compile, FMT, T1 sections). A slice that cannot
   run it is not finished, whatever it looks like.
3. **Every behaviour fix earns a rail** in `rust/test-harness/tests/` — a test that fails if the seam is re-cut.
   A fix without a rail is a claim.
4. **Never restore anything from the archive into the tree.** `$ARCHIVE = ~/Documents/forge-legacy-ts-archive-2026-10-02`.
   The TypeScript there is **specification to translate, never a module to import**. `arch_boundary__012` fails the
   moment anything under `legacy/` exists again, and it is meant to.
5. **The engine's holds are the Captain's** (`HANDOFF-ENGINE-CONTRACT-RESTORATION-2026-09-29.md` §2): no scheduler
   restart, no engine lane, no `forge:clean`. A window that needs one stops and asks.
