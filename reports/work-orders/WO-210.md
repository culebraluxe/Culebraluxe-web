# Work Order WO-210 Closure Report

## Decision
**Captain Decision C3 = keep as-is (opt-out).** No code change required.

## Rationale
Captain sees no reason to invert to opt-in; the flag stays "allow publish unless explicitly disabled."

## Context
The `FORGE_ALLOW_PUBLISH` environment variable controls whether Forge publishes candidates to `origin/main`. The current implementation in `forge/src/engine/config.rs:147-155` (`allow_publish()`) and `forge/src/engine/git_publish.rs:238-250` (`publish_switch_off()`) uses opt-out semantics:
- Unset variable → publish allowed (default true)
- Explicit `0`, `false`, `off`, or `no` → publish disabled

The proposal was to invert to opt-in semantics (unset = no publish), but the Captain has decided to keep the current behavior.

## Evidence
- `forge/src/engine/config.rs:147-155` — `allow_publish()` default is `true` when unset
- `forge/src/engine/git_publish.rs:238-250` — `publish_switch_off()` returns `false` for `None` (unset)

## Outcome
No code changes. The existing tests in `config.rs` already verify the default behavior (`child_config_defaults` test at line 206-217 asserts `assert!(cfg.allow_publish)` when `FORGE_ALLOW_PUBLISH` is unset).
