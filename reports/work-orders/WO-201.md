## Red (failing test first)

New test `engine::maestro::tests::maestro_child_env_does_not_inherit_prod_database_url`: sets sentinel `DATABASE_URL_PROD=wo201-sentinel-prod-url` in the parent, builds the allowlist after, runs `run_maestro_streaming` against a probe script printing the var.

Pre-fix output (red):

```text
test engine::maestro::tests::maestro_child_env_does_not_inherit_prod_database_url ... FAILED
the child inherited DATABASE_URL_PROD from the parent: PROD_URL=[wo201-sentinel-prod-url]
```

## Fix

In `run_maestro_streaming`: `cmd.env_clear()` before `cmd.envs(env)`, plus `cmd.env("PWD", cwd)` — the same clear-then-apply-then-pin order as `apply_vendor_env`.
