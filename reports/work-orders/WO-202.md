## Work (in-scope half)

1. **TURN_TIMEOUT code on the Maestro ceiling error, duration as seconds.** `run_maestro_streaming` previously reported `maestro turn exceeded wall-clock ceiling of {:?}` (a `Duration` debug string, no code). The code is `engine::opencode_client::TURN_TIMEOUT_CODE`, so both backends share one vocabulary.
