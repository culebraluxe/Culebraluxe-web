# WO-108: Clamp retry and timeout knobs

## Summary
Added clamping for `FORGE_DELIVERABLE_RETRIES` (1..=10) and flooring for `FORGE_TURN_TIMEOUT_MINUTES` (minimum 1 minute, "0"/"off"/"none" are floored to 1).

## Changes
1. **forge/src/engine/config.rs**: Added test functions `deliverable_retries()` and `turn_timeout_minutes()` with clamping/flooring logic, plus comprehensive tests
2. **forge/src/engine/hold.rs**: Updated `parse_deliverable_reprompt_budget()` to clamp retries to 1..=10
3. **forge/src/engine/opencode.rs**: Updated `turn_ceiling()` to floor 0/off/none to 1 minute instead of returning unbounded
4. **forge/src/engine/maestro.rs**: Updated `turn_ceiling()` with same flooring logic, updated test expectations

## Verification
- All 387 tests pass (`cargo test -p forge --lib`)
- Clippy clean - no new warnings from changes (`cargo clippy -p forge --all-targets`)
- Clamp tests pass including zero case
- Zero is refused/floored as required
