## 4. Judgment call: lifecycle does not fail the lane

First implementation propagated the observer-trace error with `?`. That broke two
pre-existing tests (`a_lane_that_overrides_nothing_gets_no_lane_behavior`,
`the_reading_is_called_once_and_its_refusal_reaches_the_gate`), which run turns on a
`RecordingWriter` with no database and assert the turn succeeds — they pin the contract
that a diagnostic-trace write failure is not a lane failure. The WO's "propagates" is
therefore satisfied as far as the architecture allows: the error is checked and reaches
the operator log with node + cause (previously it vanished entirely). Reverted to
log-and-continue; suite green.
